# PITBridge v0.2.2

An installed-wheel user can now generate editable CSV inputs without cloning
the repository or copying example tables manually. `init-csv` writes the full
synthetic scalar case; `--rolling` writes the rolling sum/mean/count case.

```bash
python -m pip install "https://github.com/dev-belly/PITBridge/releases/download/v0.2.2/pitbridge-0.2.2-py3-none-any.whl"
python -m pitbridge init-csv --out inputs/scalar
python -m pitbridge build --csv-dir inputs/scalar --out outputs/scalar
python -m pitbridge verify --out outputs/scalar

python -m pitbridge init-csv --rolling --out inputs/rolling
python -m pitbridge aggregate --csv-dir inputs/rolling --out outputs/rolling
python -m pitbridge verify-rolling --out outputs/rolling
```

Use Python 3.11+ in a virtual environment. Installation needs internet;
generation, editing, building and independent verification then work offline.
There are no third-party runtime dependencies.

Each new input directory contains three UTF-8 CSVs and a README. Existing files
and directories are refused with exit 2. Generated tables are checked against
the strict importer before publication. The scalar case has 11 observations,
15 decisions and three specifications; the rolling case has ten observations,
four decisions and three specifications. All data is synthetic. CSV intake's
`user_supplied` label does not authenticate or reclassify it as observed data.

Move scalar `tax-a-v2`'s ingestion to `2026-04-03T00:00:00Z` and rebuild a new
report: the `SME-A-4` invoice feature changes from revision 2 / 180,000 to the
then-available revision 1 / 100,000. Rolling 30-day sums remain 1,500 / 4,300 /
6,300 for the three SME-A decisions, with explicit source membership.

The checked-wheel gate runs both first-use routes outside the source tree,
compares result CSVs with the demos, refuses overwrites and replays an edited
arrival. The publisher requires this evidence before creating the release.
Existing scalar/rolling bundle formats, feature algorithms, timestamp guards
and optional downstream integration pins are unchanged. Previous releases and
their assets remain available.
